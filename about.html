About the Gallery

This website is a fictional character gallery focused on characters from Marvel.

I chose Marvel as the theme because of the large variety of characters, heroes, abilities, and stories throughout the Marvel universe.

The website was created as a static web application using HTML and CSS. The goal of the project is to practice creating multiple webpages, navigation, images, forms, and responsive layouts.

The gallery currently features Iron Man, Blade, Black Panther, Spider-Man, and Storm.
